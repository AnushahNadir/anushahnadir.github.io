Research & Projects

Few-shot industrial anomaly detection
A patch-based, few-shot defect detector built on frozen DINOv2 features with a FiLM-conditioned reference of the normal manifold. Evaluated on MVTec AD under a 10-category-train / 5-unseen-category split to measure generalization to previously unseen defect types. Collaborative work with a lab colleague — add name. Code
Battery remaining-useful-life prediction
A machine-learning ensemble predicting lithium-ion battery degradation with uncertainty quantification. A three-model architecture combining exponential-decay modeling, XGBoost, and a temporal convolutional network delivers robust predictions across operating conditions such as varying charge–discharge cycles and temperatures. Reliability and explainability come from conformal prediction and RAG-based analysis, validated with leave-one-battery-out cross-validation on the NASA / CALCE dataset (34 cells). Built with Python, PyTorch, TensorFlow, and scikit-learn.
Fruit freshness classification
A lightweight computer-vision classifier for produce freshness using transfer learning with MobileNetV3, designed to run efficiently on constrained hardware.
